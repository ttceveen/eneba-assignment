## Дедупликация и целостность

- Сессии идентифицированы по Session ID, сообщения по Message ID. Внутри одного хода дополнительно сопоставлены порядок и полный текст зеркальных пользовательских сообщений. Сообщения с разными ID сохранены, даже если текст совпадает.
- Одно зеркальное представление пользователя отличалось от первичной записи того же хода. Сохранён первичный текст. Самостоятельные AgentMessage без первичной записи сохранены из зеркала.
- Проверены формат Markdown с учётом ограждённых текстовых блоков, число сообщений и вложений, уникальность ID в сессии и совпадение каждого тела с исходным текстом после обработки чувствительных значений.
- Вызовы инструментов перечислены отдельно. Аргументы, сырые результаты, внутренние рассуждения и служебные инструкции исключены.

## Подтверждённые пробелы

- Два изображения из видимого диалога ChatGPT остаются вложениями в приложении и не встроены в Markdown. Другие ссылки на изображения, PDF и артефакты оставлены в исходных репликах. Все 57 доступных текстовых вложений включены.
- Для ChatGPT отмечено начало хода. Отдельные временные метки сообщений этот источник не дал.
- Полнота по удалённым чатам, альтернативным веткам, другим аккаунтам и сервисам не установлена. Между сессиями сохранены реальные интервалы молчания без добавления сообщений.
- Снимок F5.2 не содержит финального ответа на текущую задачу, который записывается после создания файлов.
- Если для проекта использовались другие AI-чаты, требуется добавить их подлинный Markdown-экспорт либо доступные проверяющему ссылки. Для найденного диалога о дизайне повторный экспорт текста не нужен.
