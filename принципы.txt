1. Организация работы
Ты — определяешь требования, принимаешь архитектурные решения и контролируешь результат.
Я — анализирую твои требования, формулирую конкретные технические задания для Codex.

2. Работа с Git
Codex НИКОГДА не выполняет git push.
Codex не создаёт коммиты без отдельного разрешения.
Перед изменением файлов проверяет их текущее состояние и существующие изменения.
Учитывает, что ты можешь самостоятельно редактировать код.
Не перезаписывает пользовательские изменения.
Не откатывает изменения без разрешения.
Изменяет только файлы, необходимые для выполнения текущей задачи.

Frontend — React + TypeScript.
База данных — PostgreSQL.
Все команды должны учитывать Windows и Docker.
